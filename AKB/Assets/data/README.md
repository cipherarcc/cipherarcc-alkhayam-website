# Al Khayam Restaurant — Digital Menu

A modern, mobile-first digital menu website for **Al Khayam Restaurant** (Bakery & Restaurant) located in Dubai, UAE.

---

## 🎯 Purpose

Customers scan a QR code at their table and browse the menu on their phone. They can add items to a cart and place orders via WhatsApp — no app download needed.

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Markup | HTML5 |
| Styling | CSS3 (Flexbox, Grid, Media Queries) |
| Logic | Vanilla JavaScript (ES6+) |
| Storage | Browser localStorage |
| Ordering | WhatsApp API (wa.me) |
| Hosting | GitHub Pages |
| Version Control | Git + GitHub |

**No frameworks. No backend. No database. 100% free.**

---

## ✨ Features

### Customer Site
- Full menu with 180+ items across 19 categories
- Real-time search
- Category filter with emoji icons
- Shopping cart with quantity controls
- Size options (Small / Large) for select items
- Conditional size pills (only for dual-price items)
- WhatsApp order integration
- Dark mode toggle
- Mobile-first responsive design
- Back-to-top button
- Smooth animations

### Admin Panel
- Password-protected login
- Add / Edit / Delete menu items
- Dual-price support (Small / Large)
- Export updated menu.js
- Reset to original menu
- Mobile-friendly interface

## 📝 How to Update the Menu

### Method 1: Admin Panel (Easiest)

1. Open Admin Panel: `/admin.html`
2. Login with password: `alkhayam123`
3. Add, edit, or delete items
4. Click **"Export menu.js"**
5. Replace `Assets/data/menu.js` with the downloaded file
6. Upload updated `menu.js` to GitHub
7. Website automatically updates

### Method 2: Direct File Edit

1. Open `Assets/data/menu.js` in VS Code
2. Add/edit items manually
3. Save and upload to GitHub
